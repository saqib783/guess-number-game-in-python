# 🎯 Number Guessing Game in Python

A terminal-based **Number Guessing Game** built using Python. The computer randomly selects a number between 1 and 10, and the player has to guess it correctly.

This repository serves as a practical project for my **GitHub Portfolio**.

## 🚀 Features
* **Interactive Gameplay:** Play directly inside your command line or VS Code terminal.
* **Random Generation:** Uses mathematical randomization to ensure every game has a new target number.
* **Instant Feedback:** Tells you immediately if your guess was correct or wrong.
* **Final Summary:** Shows both your guess and the computer's number at the end of the game.

---

## 🛠️ Built With (Libraries & Tools)
* **Python 3.x** - Core programming language.
* **`random` (Built-in)** - Python's standard library module used to generate randomized numbers. *No external installations or `pip install` commands are needed!*

## 💻 How to Clone and Run the Project

Follow these simple steps to download and run the game on your local machine:

### 1. Clone the Repository
Open your terminal or command prompt and run the following command to download the code:
```bash
git clone https://github.com
```

### 2. Navigate to the Directory
Go into the project folder:
```bash
cd guess-number-game-in-python
```

### 3. Run the Game
Execute the Python file using your terminal:
```bash
python guess.py
```

---

## 🎮 How to Play
1. Once the game starts, you will see a prompt in the terminal: `guess a number`.
2. Enter any number between **1 and 10**.
3. The game will instantly check your answer:
   * If you guess correctly, it displays: `your guess is superb` 🎉
   * If you guess wrong, it displays: `your guess is not correct` ❌
4. At the end, the system reveals the exact number selected by the computer.
